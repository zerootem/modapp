# ModWeeb Theme — قالب بلوجر لمود ويب

قالب بلوجر عربي أولًا، مبني ليعرض مقالات **مولّد المقالات ModWeeb** بنفس شكلها داخل الأداة حرفيًا: العناوين حتى H6، المقدمة Dropcap، الملاحظات والتنبيهات، الخطوات، الأكورديون، الأسئلة الشائعة، جدول المحتويات، الاقتباسات، الجداول، الأكواد، والتمييز والضباب.

الإصدار: **1.0.0** · الترخيص: MIT · التطوير: [ModWeeb](https://modweeb.com)

---

## الملف الجاهز للرفع

```
dist/modweeb-theme-v1.0.0.xml
```

هذا الملف وحده يكفي. لا يحتاج إلى بناء أو مكتبات خارجية.

## التركيب على بلوجر

1. من لوحة بلوجر افتح **المظهر (Theme)** ← السهم بجانب «تخصيص» ← **النسخ الاحتياطي / استعادة**.
2. اضغط **تنزيل** لأخذ نسخة من قالبك الحالي (احتياطًا).
3. ارجع إلى نفس النافذة واضغط **تحميل (Upload)** واختر `modweeb-theme-v1.0.0.xml`.
4. افتح **التخطيط (Layout)** ورتّب الأدوات:
   - **الترويسة (Header):** ارفع شعار المدونة من إعدادات الأداة (اختياري؛ بدون شعار يظهر شعار ModWeeb المدمج).
   - **الصفحات (Pages):** اختر الصفحات التي تظهر في شريط التنقل وفي التذييل (من نحن، الخصوصية، الشروط…).
   - **الشريط الجانبي:** يظهر بجانب المقالات؛ أضف «الأكثر قراءة»، «الوسوم»، أو أي أداة تريدها.
5. من **الإعدادات** فعّل «وصف المدونة» ليظهر تحت الشعار، وفعّل التعليقات إن رغبت.
6. احفظ، ثم افتح المدونة وتأكد من: الشعار، التنقل، الوضع الليلي، تبديل لغة الواجهة، وفتح مقال من مقالاتك.

> بعد الرفع قد تحتاج إلى إعادة تفعيل **التسميات** في التخطيط إن كانت مخفية.

## الميزات في v1.0

- **هيدر زجاجي ثابت** مع شعار، وصف، تنقل، بحث، ومفتاح مظهر.
- **6 ألوان سمة** × **4 أوضاع**: تلقائي (حسب النظام)، فاتح، ناعم (مشبع بلون السمة)، داكن. الاختيار يُحفظ في المتصفح ولا يرتد عند إعادة التحميل.
- **6 لغات لواجهة القالب**: العربية، الإنجليزية، الفرنسية، الإسبانية، التركية، الأردية — مع تبديل الاتجاه RTL/LTR تلقائيًا. محتوى المقالات يبقى بلغته الأصلية.
- **الرئيسية:** مقال مميز، أحدث المقالات، بطاقات بصور الكاتب والتاريخ والوسوم، ترقيم صفحات.
- **صفحة المقال:** فتات تنقل، بيانات الكاتب والتاريخ ووقت القراءة وعدد التعليقات، وسوم، شريط مشاركة (واتساب، X، فيسبوك، تيليجرام، لينكدإن، نسخ الرابط)، مقالات ذات صلة تلقائية حسب الوسم، تعليقات بلوجر.
- **أنماط كاملة لمخرجات مولد المقالات** (انظر الجدول أدناه).
- **جدول محتويات تلقائي**: الأداة تولّد `details.sp.toc` فارغًا، والقالب يملؤه من عناوين H2/H3.
- **بيانات منظمة:** WebSite + SearchAction، BlogPosting، FAQPage (تُبنى تلقائيًا من أكورديون الأسئلة)، Open Graph وTwitter Card.
- **قراءة مريحة:** شريط تقدم القراءة، زر العودة للأعلى، نسخ الكود، تكبير الصور، كشف النص المخفي، دعم الطباعة.
- **أداء:** بلا jQuery أو React؛ CSS واحد وJS صغير (≈24 كيلوبايت قبل الضغط)، خط واحد.

## توافق مولد المقالات

| العنصر في الأداة | ما يظهره القالب |
|---|---|
| `h1`–`h6` مع `data-before` / `data-after` | عناوين بأحجام متدرجة، وخط فاصل لـ H2، وبادئة/لاحقة ملونة |
| `<p><span class="dropCap">` | حرف استهلالي كبير بلون السمة |
| `<p class="pIndent">` | فقرة بخط جانبي ملون |
| `<p class="pRef">` | صندوق المصدر بحدود متقطعة |
| `p.note` / `.wr` / `.qs` | ملاحظة معلومات/تحذير/سؤال |
| `.alert.info|warning|success|error|tip|question[.outline]` | تنبيهات ملونة بنمطي التعبئة والحدود |
| `ol.steps` | خطوات مرقمة ببطاقات دائرية |
| `.kp-wrap .kp-item` | محاور على شكل وسوم بعلامة ✓ |
| `details.ac` / `.ac.alt` / `.sp` / `.showH` | أكورديون بأسهم دوارة |
| `details.sp.toc > .aToc` | جدول محتويات يُبنى تلقائيًا |
| `div.showH[itemtype="FAQPage"]` | أسئلة شائعة + JSON-LD تلقائي |
| `blockquote.editorial|soft|pull|policy` | 4 أنماط اقتباس |
| `.table` + `bordered stripped hovered primary…` | جداول بكل أنماط الأداة |
| `pre[data-source]`, `.pre.tabs`, `code`, `kbd` | كود بأسماء ملفات، تبويبات، ونسخ سريع |
| `.spoiler`, `mark` | ضباب يكشف بالنقر، وتمييز |
| `a.button[.ln]`, `.downloadBox`, `.pRelate` | أزرار وصناديق تحميل وروابط ذات صلة |
| `.zmImg` | تكبير الصورة بنقرة |

ملف اختبار جاهز: `samples/sample-article.html` — الصقه في مقال جديد بوضع HTML ثم عاينه.

## التخصيص

**من «تخصيص» في بلوجر (Theme Designer):** لون السمة، خلفيات الصفحة والبطاقات، ألوان النص والعناوين والحدود، الخط، عرض المحتوى، انحناء البطاقات، ارتفاع الهيدر.

> ملاحظة: ألوان السمة المختارة من زر المظهر داخل الصفحة تتجاوز متغيرات Theme Designer أثناء الاستخدام، لأنها مصممة لتطابق لوحة ألوان مركز الأدوات. إن أردت قفلها على لون واحد، احذف الأزرار من `src/template.xml` أو اجعل `data-accent` ثابتًا.

**متغيرات CSS** متاحة لأي تعديل إضافي:

```css
--mw-accent, --mw-accent-soft, --mw-bg, --mw-card, --mw-card-alt,
--mw-heading, --mw-text, --mw-muted, --mw-border, --mw-radius,
--mw-header-h, --mw-prose-width, --mw-width
```

## التطوير والاختبار

```bash
cd blogger-theme
npm run build      # يبني dist/modweeb-theme-vX.xml ويتحقق من صحة XML
npm run preview    # معاينة محلية على http://127.0.0.1:4300/preview/
python3 test-preview.py   # 20 اختبارًا آليًا (تجاوب، أخطاء، TOC، FAQ، الوضع الليلي، اللغة)
```

البنية:

```
src/template.xml   هيكل بلوجر (b:section, b:widget, b:includable)
src/skin.css       كل الأنماط + متغيرات Theme Designer
src/theme.js       اللغات، الألوان، TOC، المشاركة، الضوء…
preview/           معاينة محلية (ليست جزءًا من الملف النهائي)
samples/           مقال اختبار لكل العناصر
```

## قيود الإصدار 1.0

- لا توجد روابط «المقال السابق/التالي» بعد (تتطلب جلب Feed إضافيًا).
- «المقالات ذات الصلة» تظهر فقط للمقالات التي تحمل وسمًا واحدًا على الأقل، وتُجلب عبر Feed بلوجر.
- نموذج التعليقات يستخدم إطار بلوجر الرسمي؛ يتطلب تفعيل التعليقات في إعدادات المدونة.
- تبديل لغة الواجهة يغيّر نصوص القالب فقط، لا محتوى المقالات.
- عند استخدام نطاق مخصص يجب أن تكون صفحات الخطوط غير محجوبة في بلد الزائر.
