# ModApp — مركز الأدوات التوليدية

مركز عربي يجمع أدوات ويب عملية في واجهة واحدة. يعرض المشروع كل أداة كبطاقة مستقلة، ويعمل على GitHub Pages دون خادم تطبيق خاص.

**الموقع المنشور:** [zerootem.github.io/modapp](https://zerootem.github.io/modapp/)

## الأدوات

- **ضاغط الأكواد:** ضغط وتنسيق CSS وJavaScript وHTML، مع خيارات للتعليقات والفراغات و`console`، إضافةً إلى التراجع والنسخ والتنزيل. يستخدم JavaScript محرك Terser المضمّن في التطبيق بدلاً من إزالة الفراغات بالتعبيرات النصية.
- **تحويل الصور إلى SVG:** تحويل صورة محلية إلى رسم SVG مع التحكم بعدد الألوان ومستوى التفاصيل، ومعاينة النتيجة ونسخها أو تنزيلها.
- **مولد الصور المصغرة بالذكاء الاصطناعي:** محرر Canvas لتصميم صور المقال وتصديرها، مع توليد اختياري لخلفية أو شخصية أو رمز ومساعد يقترح ألواناً وخطاً ووسوماً من عنوان المقال ووصفه.
- **مولّد المقالات:** تفتح البطاقة المولّد المنشور داخل إطار مدمج في مركز الأدوات، مع خيار ملء الشاشة. يبقى التطبيق الأصلي مستقلاً في مستودعه وصفحته، ويُحمّل داخل `iframe` دون تغيير تخطيطه أو ملفاته.

## التشغيل محلياً

يتطلب المشروع Node.js وnpm:

```bash
npm ci
npm run dev
```

وللتحقق والبناء:

```bash
npm run lint
npm test
npm run build
```

ينشئ `npm run build` نسخة الموقع في `dist/`. بعد تهيئة صلاحية النشر إلى GitHub Pages، ينفذ `npm run deploy` البناء ثم ينشر ملفات `dist/` إلى فرع `gh-pages`.

## الخصوصية والاعتماديات

يعالج محوّل الصور الملفات في المتصفح ولا يرفعها إلى خادم التطبيق. يحتاج تحميل مكتبة ImageTracer من jsDelivr عند استخدام المحوّل، لذلك يلزم اتصال بالإنترنت لتحميل المكتبة أول مرة. يحفظ ضاغط الأكواد نص الجلسة وخياراتها، ويحفظ مولد الصور إعدادات التصميم والصور المستخدمة، في `localStorage` على المتصفح المستخدم. عند طلب توليد صورة أو تشغيل مساعد التصميم تُرسل الأوصاف أو عنوان المقال ووصفه إلى Pollinations Classic؛ استخدام الواجهة بلا مفتاح لا يضمن توفرها أو استمرار الحصة المجانية، وقد تسجل الخدمة بيانات تقنية وتحتفظ بالمخرجات مؤقتاً (عادةً حتى نحو 30 يوماً بحسب سياسة الخدمة). راجع سياسة الخدمة ولا تُدخل معلومات حساسة.

## بنية المشروع

- `src/pages/`: صفحات قائمة الأدوات وصفحات كل أداة، بما فيها صفحة «من نحن» وإطار مولّد المقالات.
- `src/components/`: مكونات الأدوات والواجهة المشتركة.
- `src/minifyJavaScript.js`: منطق ضغط JavaScript.
- `src/context/`: حالة الثيم.
- `public/`: الأيقونات والملفات العامة.

إعداد المسار الأساسي لـGitHub Pages موجود في `vite.config.js`، وتُعرّف المسارات داخل التطبيق باستخدام `HashRouter` لتعمل الصفحات الفرعية على الاستضافة الثابتة.
